# 原创视觉方案：夜架 NIGHT SHELF

## 概念

独立书店像城市夜里仍亮着的一格书架。视觉关键词是：

- 墨蓝夜空；
- 纸张米色；
- 书签灯的金色；
- 等高线/星图般的地图底纹；
- 书脊符号 `▰▰▱`。

## 色彩

- 主背景：`#f5ecd9` 纸色；
- 深色区：`#101b2a` 墨蓝；
- 灯色：`#e9b44c` 金、`#f2d184` 浅金；
- 营业：`#83a08b` 鼠尾草绿；
- 闭店：`#c86f52` 砖红。

## 地图

内置 SVG 使用：

- 径向渐变模拟夜空光晕；
- 透明贝塞尔路径表示城市/阅读路线；
- 圆形聚合点像书桌上的地图钉；
- 营业/闭店/聚合三色图例；
- 不使用真实地图瓦片，保证离线可演示和视觉统一。

## 组件

- 搜索卡：纸面卡片浮在深色 hero 上；
- 门店卡：纸张边框、标签胶囊、状态徽章；
- 状态徽章只与服务端状态绑定；
- Toast 用于抢占席位结果；
- 弹窗承载活动和报名；
- 网络失败横幅明确展示上次更新时间。

## 可访问性

- SVG 聚合点可键盘 focus；
- 表单均有关联 label；
- 网络/报名结果使用 alert/live region；
- 字号、对比度和触控区域适配移动端；
- 移动端布局自动折叠为单列。
